## Download App

Each app card includes a **Download App** button.

Place the corresponding IPA files in:

```text
downloads/
```

For example:

```text
downloads/
├── Animal Sounds 2.0.ipa
├── SoundTouch 1.4.ipa
├── Tozzle 3.7.ipa
├── AutismXpress 1.0.ipa
└── ...
```

The website can then reference each file using a relative URL such as:

```text
./downloads/Animal%20Sounds%202.0.ipa
```

## GitHub Pages

The project is designed to work as a static GitHub Pages site.

Recommended deployment:

```text
Repository
   │
   ├── index.html
   ├── styles.css
   ├── app.js
   ├── downloads/
   └── .github/workflows/pages.yml
```

Enable GitHub Pages from:

**Repository → Settings → Pages**

Select the GitHub Actions deployment method.

## GitHub Codespaces

Open the repository in GitHub Codespaces and run a local static server.

Example:

```bash
python3 -m http.server 8000
```

Then open port **8000** in Codespaces.

## Important

An IPA file is a packaged iOS application. A download button can distribute the file, but whether a particular historical IPA can actually be installed on a device depends on iOS version, signing/provisioning, device compatibility, and Apple's installation requirements.

The metadata displayed by this website describes the archive supplied to the project.
